# GeoPics

上传带 EXIF 的原图，自动读取拍摄经纬度与日期，结合 Mapbox 静态地图，在 Canvas 2D 上合成"地图 + 照片 + 城市大字 + 坐标日期"的创意海报。

## 使用前配置

1. Mapbox Public Token（`pk.…`）写在 `utils/config.local.js` 的 `mapboxToken`。仓库公开，GitHub 会拦截含 token 的提交，填写后执行 `git update-index --skip-worktree utils/config.local.js` 避免误提交（开发者工具上传时仍会打包该文件）。建议在 Mapbox 账号里为 token 设置 URL 限制。样式可在 `utils/config.js` 的 `mapbox.username` / `styleId` 中替换为自己在 Mapbox Studio 制作的样式。
2. 小程序后台「服务器域名」中，把 `https://api.mapbox.com` 加入 `request` 与 `downloadFile` 合法域名（开发阶段可在开发者工具中勾选"不校验合法域名"）。
3. `project.config.json` 的 `appid` 为本小程序的 AppID。`wx.chooseLocation` 需要 `app.json` 中的 `requiredPrivateInfos`（已配置）。

未配置 token 时不会请求网络，海报使用本地绘制的简约底图，方便离线调试；开发版 / 体验版的首页会显示一行开发提示，正式版不显示。

## 界面

整体参照 iOS 设置 / App Store 的视觉语言：

- **字体与配色**：系统字体栈（iOS 上为 SF Pro + 苹方，其他平台回退到系统无衬线字体）；系统灰底 `#F2F2F7`、白色圆角分组、强调色 `#007AFF`、开关绿 `#34C759`；文字分主 / 次 / 三级灰，分隔线为左侧缩进的 0.5px 发丝线。
- **布局**：页面内是大标题 `GEOPICS`，滚出视野后导航栏才显示标题；右侧是「?」（帮助与关于）和会员胶囊。选好照片后，模板分类与模板标签位于预览上方，点选即可在下方预览中看到效果；没有照片时点按预览即可选图。预览宽度按屏幕高度自适应，保证模板栏与带底栏的整张海报同时在首屏露出。其余设置按「分组标题 + 白色分组 + 灰色说明」排列：照片 / 地点与日期 / 照片取景 / 地图 / 不透明度 / 海报（品牌底栏开关、导出尺寸）。
- **控件**：分段控件（统一 / 随机模板、模板分类、地名语言与范围）、胶囊模板标签、圆形配色色板、iOS 式开关与滑块。模板标签与照片缩略图条铺满屏宽横向滑动，自动滚动到选中项时与页边距对齐。切换模板有轻触反馈。保存 / 下载固定在底部半透明工具栏（适配安全区），付费面板与地点搜索为底部弹层。原生 canvas 的层级高于普通节点，弹层出现前会把预览截成图片顶替并隐藏 canvas，弹层全部关闭后再恢复并重绘，避免预览图盖在弹层上方。
- `index.js` 的 `PREVIEW_RESERVED_RPX` 对应 wxss 中大标题、模板栏、预览说明、底部工具栏的高度，改动这些样式时需同步。

## 地图与署名

- 使用在线地图时，静态图请求带 `attribution=false&logo=false`（自带角标会随模板裁切被遮住），改由海报在每个模板固定的位置绘制 Mapbox 标志与「© Mapbox © OpenStreetMap」，满足 Mapbox 的署名要求。帮助页底部同样列出地图数据来源。
- 未配置 token 或地图下载失败时，按地点生成稳定的城市街区示意底图（河流 / 海岸、街网、公园、干道），区分浅色与深色主题；此时海报不绘制 Mapbox 署名。下载失败只提示一次，失败结果不缓存，网络恢复后调整缩放或切换模板即可重新加载。

## 地名范围

- 解析照片 GPS 得到地名时，**默认只显示城市**（「地名范围」：城市），过长的德语 / 英语城市名会去掉限定后缀（如 `St. Wolfgang im Salzkammergut` → `ST. WOLFGANG`，`Frankfurt am Main` → `FRANKFURT`），避免超出海报边界。没有城市级结果时依次退到 locality / district / region / country。
- 需要更细时切换为「含区域」，显示为 `RIED, ST. WOLFGANG`（中文为 `杭州市西湖区`）。手动修改过的地名不会被范围切换覆盖。
- 各模板的地名字号自适应范围放宽：名称特别长时会比原最小字号再缩小一些，而不是超出边界。

## 批量

- 选择照片时可一次多选，最多 9 张（`utils/batch.js` 的 `MAX_BATCH`）；点缩略图末尾的 + 可继续添加或重新选择。导入时显示逐张进度。每张照片独立保存位置、地名、日期、取景，缩略图上标有“无位置”的可点选后手动选点。
- **统一模板**：所有照片使用同一模板，点选模板即统一切换。**随机模板**：每张照片各用不同模板（在当前分类内抽取，切换分类会重新随机；把模板洗牌后依次发牌，一轮用完再开始下一轮，相邻不重复），可「重新随机」；点选缩略图后再选模板只改当前这张。
- 地点 / 日期默认只改当前这张；有多张照片时，编辑后点「应用到全部照片」，可选择统一地点和日期、仅地点或仅日期（坐标各自保留，统一后的地名视为手动地名）。
- 缩略图左上角圆圈勾选用于下载，当前这张右上角的 × 可移除。地图配色、不透明度、地名语言、地图缩放为全局设置。
- 下载：底部工具栏「保存当前」，以及「下载全部 N 张」（部分勾选时为「下载所选 N 张」），逐张导出 1200 × 1600 / 1792 并显示进度，批量导出期间保持屏幕常亮。以下情况会立即停止并说明已保存几张：未同意隐私保护指引、相册权限被拒绝（引导去设置）、cloud 模式扣额度时网络异常、服务端认定额度不足（打开付费面板，购买后继续）。其余失败会汇总提示。

## 会员

- **免费额度**：每位用户默认有 **2 张**免费额度（`config.membership.freeQuota`）。额度内预览无水印，可直接保存；每保存一张消耗 1 张，同一张照片再次保存不重复计费。免费额度用完后才显示斜向平铺的 `GEOPICS · PREVIEW` 水印，且**不支持下载**（点击保存会弹出付费面板）。免费额度优先于会员额度包消耗，购买会员不会重置已用的免费额度；邀请码会员不限量。
- **权益存放位置**：`payment.mode = 'mock'`（本地开发用，当前配置已切为 `'cloud'`）时，免费额度已用张数、会员和邀请码只存在本地缓存，清缓存会重置，也可被绕过；`'cloud'` 时全部以云函数记录的为准（按用户 openid），小程序只缓存服务端返回的快照。收费上线请使用 `'cloud'`，见下文「接入微信支付」。回到首页时会向服务端同步权益（两次同步至少间隔 30 秒；支付结果确认中时不受此限制）。
- **去水印并可下载**的三种方式：
  1. **邀请码**：不区分大小写，兑换后永久享有会员权益、不限张数。mock 模式读 `utils/config.js` 的 `membership.inviteCodes`（上线配置中已清空；本地调试可临时填入）；cloud 模式在云函数环境变量 `INVITE_CODES` 里配置，客户端不再需要保存邀请码，同一用户 1 小时内连续输错 10 次会被暂时锁定。
  2. **开通会员（有额度）**：

     | 方案 | 价格 | 额度 | 有效期 |
     | --- | --- | --- | --- |
     | 单张解锁 | ¥1.29 | 1 张 | 长期有效，用掉为止（mock 模式仅限购买时的这张照片，本次使用期间） |
     | 月度会员 | ¥14.9 | 120 张 / 月 | 30 天 |
     | 年度会员 | ¥109.9 | 2000 张 / 年 | 365 天 |

     价格（单位：分）、额度、有效期均在 `membership.plans` / `membership.single` 中配置。付费面板会标出每档的单张均价，并高亮均价最低的一档。
  3. **单张解锁**：cloud 模式下是 1 张一次性额度，可用于任意一张照片，先于额度包消耗；mock 模式只解锁购买时的那张照片，移除或重新选图后需再次购买。
- **额度规则**：每保存一张无水印海报消耗 1 个额度；同一张照片在本次会话内再次保存不重复计费。每次购买是独立的一包额度（有效期从购买时起算），多次购买可叠加，优先消耗最早到期的一包。额度用完或到期后水印恢复。
- **超出额度**：保存时额度不足会询问是否「仅下载」额度内的部分，或「去解锁 / 购买会员」打开付费面板；额度完全用完则直接打开付费面板并提醒。购买成功后自动继续刚才的下载。（`wx.showModal` 的按钮文字最多 4 个字符，超出时弹窗会直接失败，张数因此写在正文里。）
- 批量下载时，只会下载已解锁 / 额度内的照片。部分照片已解锁时，未解锁的缩略图带“水印”标记；大标题右侧的胶囊显示当前状态（如“开通会员”“会员 · 117 张”），点击可打开付费面板查看各额度包的剩余与到期时间。
- **iOS**：平台规范不允许 iOS 小程序内直接售卖虚拟商品，因此 `payment.iosPurchase` 默认为 `false`：iOS 上付费面板只显示「由于相关规范，iOS 暂不支持在小程序内购买」、当前额度与邀请码兑换，不显示价格与购买按钮，各处文案也不带“开通 / 续购”等引导；已有权益（包括在其他设备购买的）照常使用。接入合规的 iOS 支付方案后再改为 `true`。开发者工具的平台为 `devtools`，不受此限制。

### 接入微信支付（云开发方案）

代码里已包含完整链路：小程序 `utils/payment.js` ⇄ 云函数 `cloudfunctions/api`（微信云开发 + 云支付）。配置文件当前已是 `cloud`；云函数尚未部署时无法保存无水印海报，本地调试请临时改回 `mock`。

**流程**

1. 用户点购买 → `createOrder`：云函数按**服务端商品目录**（`cloudfunctions/api/catalog.js`，价格不取自客户端）写入订单（`orders`）并调用 `cloudPay.unifiedOrder`，返回支付参数。
2. 小程序 `wx.requestPayment` 拉起收银台。
3. 微信把结果通知发给云函数（回调），云函数校验金额后**在一个数据库事务里**把订单置为已支付并发放权益（月度 / 年度加一包额度，单张加 1 次单张额度），重复通知不会重复发放。
4. 小程序随后调用 `syncOrder` 向服务端确认，以服务端返回的权益快照为准。`requestPayment` 成功只表示用户走完了支付流程，本地不会据此发放权益；若回调稍有延迟，会提示“支付结果确认中”，并在稍后 / 回到页面时自动同步。回调丢失时，`syncOrder` / `getEntitlement` 会主动 `queryOrder` 查单补偿。
5. 保存海报前，小程序向云函数 `consume` 扣 1 张额度（顺序：免费额度 → 单张额度 → 最早到期的额度包），额度不足服务端会拒绝，页面弹出付费面板。计费键为“本次打开小程序 + 照片序号”，同一张照片重试不重复扣。

**部署步骤**

1. **主体与商户号**：小程序主体须为企业 / 个体工商户。在微信支付商户平台申请商户号并关联小程序 AppID；再到云开发控制台开通「微信支付」，获得**子商户号**（`SUB_MCH_ID`）。
2. **开通云开发**：开发者工具里创建云开发环境，记下环境 ID，填入 `utils/config.js` 的 `payment.cloud.env`。
3. **数据库**：创建集合 `users` 与 `orders`，权限都设为**所有用户不可读写**（云函数不受限制），避免小程序端直接改额度或订单。
4. **云函数**：右键 `cloudfunctions/api` 选“上传并部署：云端安装依赖”。在云开发控制台该函数的环境变量里设置：
   - `SUB_MCH_ID`：云支付子商户号（必填）
   - `INVITE_CODES`：邀请码，多个用英文逗号分隔（如 `geo0930`）
   - `ENV_ID`、`PAY_CALLBACK_FUNCTION`：可选，默认当前环境和函数 `api`
5. **切换模式**：`utils/config.js` 里 `payment.mode` 改为 `'cloud'`，并把 `membership.inviteCodes` 清空（cloud 模式不再读它）。
6. **测试**：把 `cloudfunctions/api/catalog.js` 和 `utils/config.js` 里的价格同时临时改成 1 分钱，用体验版 + 体验成员真实支付、再在商户平台退款；小程序不能用微信支付沙箱。确认订单变为 `paid`、`users` 里额度正确、重复发送回调不会重复加额度。改回正式价格后再提审。

价格、额度、免费张数必须在 `catalog.js` 与 `utils/config.js` 两处保持一致，`tests/cloud.test.js` 会校验不一致。

**需要你在上线前核对的事项**

- **iOS 虚拟商品支付规则**：iOS 端默认不提供购买（见上文「iOS」）。如需在 iOS 上售卖，请对照最新的《微信小程序运营规范》与虚拟支付文档接入合规方案后，再打开 `payment.iosPurchase`。
- **云开发接口字段**：`unifiedOrder` 的回调事件字段、`queryOrder` 的入参和返回字段以云开发官方文档为准，代码里做了保守处理（异常一律视为未支付），但没有在真实商户环境验证过，请用 1 分钱订单完整走一遍。
- **退款**：目前没有退款接口，帮助页也没有写退款政策。退款后需要人工在 `users` 里回收对应额度（或自行增加调用 `cloudPay.refund` 的云函数）；如有退款规则，请补充到帮助页。
- 出图仍在手机上完成，服务端只能约束“出无水印图之前必须先扣额度”，无法阻止用户用其他手段绕过客户端；这对本产品的定位通常足够。

## 品牌底栏与水印

- **品牌底栏**（「海报 · 品牌底栏」开关，默认开启，偏好会记住）：在海报底端拼接一条 64 逻辑单位高的信息栏——GEOPICS 标志（经纬线地球 + 定位点）、字标与标语，配置小程序码后码图放在右侧；关闭后海报恢复 3:4，导出尺寸为 1200 × 1600，开启时为 1200 × 1792。所有用户都可以自由开关。
- **小程序码**：微信不能在图片里放可点击的链接，海报上应放小程序码。小程序码图片放在 `assets/miniprogram-code.png`，路径配置在 `utils/config.js` 的 `brand.qrcode`。未配置或文件不存在时，底栏只显示居中的一行 GEOPICS 标志、字标与标语，不放任何提示文字；配置后标志靠左、小程序码在右。
- **免费版水印**已调淡、调疏：小字号、低不透明度，仅覆盖海报主体，不覆盖底栏。

## 大尺寸原图

手机原图（12MP~48MP）直接放进 canvas 时，部分机型只能解码出上半部分，下半部分会变成“最后一行像素”的竖向拖影。导入时会先用 `wx.compressImage` 把长边超过 `image.maxSide`（默认 2560px）的照片等比压缩（质量 92），EXIF 位置 / 日期仍从原图读取；压缩失败则退回原图。海报导出仍是 1200 × 1600 / 1792，照片放大到 2 倍取景时仍能满足清晰度。

## 导出

预览 Canvas 按屏幕 dpr 渲染；保存时使用页面外的隐藏 Canvas，按逻辑尺寸 400 × 533.33（带底栏时 400 × 597.33）的 3 倍绘制，即 1200 × 1600 / 1792，经 `wx.canvasToTempFilePath` 输出 JPG 并调用 `wx.saveImageToPhotosAlbum`。

## 说明与限制

- 必须选择原图（`sizeType: ['original']`），压缩图会丢失 EXIF；读取失败会提示并引导手动选点（全球搜索，或 `wx.chooseLocation` 微信地图选点，GCJ-02 会自动转换为 WGS-84）。
- 内置 EXIF 解析器取代 `exif-js`（后者依赖 DOM/XHR，无法在小程序中运行），支持 JPEG，并对 HEIC 做头部扫描兜底。
- 图片的 EXIF 方向（Orientation）目前依赖微信 Canvas 对图片的默认处理，未做额外旋转。

## 上线清单

代码侧已就绪的配置：`payment.mode = 'cloud'`、`membership.inviteCodes` 为空、`payment.iosPurchase = false`、`brand.qrcode` 已指向小程序码、提交到仓库的 `utils/config.local.js` 不含 token。上线前还需要在后台完成：

1. **服务器域名**：`request` 与 `downloadFile` 合法域名加入 `https://api.mapbox.com`。
2. **用户隐私保护指引**（「设置 → 服务内容声明 → 用户隐私保护指引」）：声明「选中的照片或视频信息」（`wx.chooseMedia`）、「相册（仅写入）权限」（`wx.saveImageToPhotosAlbum`）、「位置信息」（`wx.chooseLocation`），用途与帮助页的隐私说明保持一致，并写明照片的经纬度与搜索关键词会发送给 Mapbox。未声明的接口会调用失败（errno 112）；用户拒绝时（errno 104），页面会提示需要同意隐私保护指引。
3. **接口权限**：如后台提示，在「开发管理 → 接口设置」中开通 `wx.chooseLocation`（地图选点）。
4. **客服**：在后台「客服」中绑定客服人员，帮助页的「联系客服」才有人接待；「意见反馈」的内容在后台「用户反馈」中查看。
5. **云开发与支付**：按上文「部署步骤」部署云函数、配置环境变量与数据库权限，并用 1 分钱订单在体验版完整走一遍。
6. **服务类目**与实际功能（图片制作、虚拟商品售卖）一致；如有用户协议或退款规则，补充到帮助页。
7. **真机回归**（iOS 与安卓各一台，体验版）：选图（含无定位、经聊天转发的照片）、首次保存时的隐私弹窗与相册授权、拒绝后到设置重新开启、批量保存、转发卡片与朋友圈单页、免费额度用完后的购买 / 邀请码、弱网与断网。
