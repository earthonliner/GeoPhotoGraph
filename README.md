# GeoPics

上传带 EXIF 的原图，自动读取拍摄经纬度与日期，结合 Mapbox 静态地图，在 Canvas 2D 上合成"地图 + 照片 + 城市大字 + 坐标日期"的创意海报。

## 目录结构

```
.
├── app.js / app.json / app.wxss / sitemap.json   # 小程序入口与全局配置
├── project.config.json                            # 开发者工具配置（appid 请替换）
├── utils/
│   ├── config.js          # Mapbox token / 样式 ID 等配置
│   ├── exif-parser.js     # ArrayBuffer EXIF 解析：GPS(DMS→十进制)、拍摄日期、方向
│   ├── map-service.js     # 逆地理编码、全球地点搜索、静态图 URL、下载、GCJ-02→WGS-84
│   ├── batch.js           # 批量随机模板：洗牌发牌，一轮内不重复
│   ├── membership.js      # 会员状态：邀请码 / 月度年度额度包（本地缓存）、扣减、到期与文案
│   ├── payment.js         # 支付适配层：mock（开发）/ cloud（云函数下单 + wx.requestPayment）
│   ├── themes.js          # 地图配色预设与自定义颜色解析
│   ├── place-name.js      # 地名规范化：英文 / 中文，汉字短名转拼音、长名转首字母缩写
│   └── pinyin-data.js     # 汉字→拼音数据（由 pinyin-pro 生成）
├── pages/index/
│   ├── index.wxml         # 上传区 / 模板 Tab / Canvas 预览 / 缩放 / 保存
│   ├── index.wxss         # 黑白灰极简样式
│   ├── index.js           # 业务流程 + 三种海报样式的 Canvas 绘制 + 3x 导出
│   └── index.json
└── tests/utils.test.js    # EXIF 解析 / URL 拼接 / 坐标转换的单元测试
```

## 使用前配置

1. 编辑 `utils/config.js`，填入 Mapbox Public Token（`pk.…`），可替换为自己在 Mapbox Studio 中制作的黑白样式（`username` / `styleId`）。
2. 小程序后台「服务器域名」中，把 `https://api.mapbox.com` 加入 `request` 与 `downloadFile` 合法域名（开发阶段可在开发者工具中勾选"不校验合法域名"）。
3. 把 `project.config.json` 的 `appid` 换成自己的 AppID。`wx.chooseLocation` 需要 `app.json` 中的 `requiredPrivateInfos`（已配置）。

未配置 token 时不会请求网络，海报使用本地绘制的简约底图，方便离线调试。

## 模板

模板按分类选择：**热门**（精选跨分类的常用款）、**简约**、**经典**、**杂志**、**复古**。随机模板时，抽取范围就是当前所选分类。

| 分类 | 样式 | 说明 |
| --- | --- | --- |
| 简约 | 极简白卡 | 宽边留白，照片下方一行细字（地名 / 日期 / 坐标），适合整批统一 |
| 简约 | 底栏 | 照片通栏，底部主题色信息栏 + 右侧迷你地图 |

| 简约 | 影幕 | 宽银幕画幅，上下主题色黑边，字幕式地名 |
| 简约 | 坐标 | 全幅照片 + 四角测绘标记，经纬度作为主视觉 |
| 经典 | 拍立得 | 地图全屏背景 + 白边/投影相框，左上大字地名，坐标日期，底部衬线标语 |
| 经典 | 上下分割 | 上 40% 地图 + 大字地名与坐标，下 60% 照片 |
| 经典 | 地图徽章 | 照片全屏 + 底部渐变 + 圆形地图徽章与地名 |
| 杂志 | 杂志封面 | 全屏照片，超大衬线刊头地名 + 细线栏目，斜体封面标语，右下迷你地图 |
| 杂志 | 玻璃卡片 | 全屏照片，日期胶囊，底部半透明深色玻璃面板含迷你地图与地名信息 |

| 复古 | 胶片 | 暗房底色，35mm 片基与齿孔，琥珀色相机背刻日期（`'24 06 16`），迷你地图格 |

所有模板都支持地图配色、地图 / 照片 / 文字不透明度；除拍立得、画廊展签（完整显示照片，无需裁切）外，其余模板都支持照片取景调整。分类与模板 Tab 均可横向滑动。

## 批量

- 选择照片时可一次多选，最多 9 张，也可通过「继续添加」追加；每张照片独立保存位置、地名、日期、取景，缩略图上标有“无位置”的可点选后手动选点。
- **统一模板**：所有照片使用同一模板，点选模板 Tab 即统一切换。**随机模板**：每张照片各用不同模板（在当前分类内抽取，切换分类会重新随机）（把全部模板洗牌后依次发牌，一轮用完再开始下一轮，相邻不重复），可「重新随机」；点选缩略图后再选模板只改当前这张。
- PLACE / DATE 默认只改当前这张；有多张照片时，编辑后点「地名应用到全部」/「日期应用到全部」即可统一（坐标各自保留，统一后的地名视为手动地名）。
- 缩略图左上角圆点勾选用于下载，右上角 × 移除。地图配色、不透明度、地名语言、地图缩放为全局设置。
- 下载：「保存当前海报」、「下载所选」、「下载全部」，逐张导出 1200 × 1600 并显示进度；相册权限被拒绝时终止并引导设置，部分失败会汇总提示。

## 会员

- **免费版**：预览画面带斜向平铺的 `GEOPICS · PREVIEW` 水印，且**不支持下载**（点击保存会弹出付费面板）。
- **去水印并可下载**的三种方式：
  1. **邀请码**：`utils/config.js` 的 `membership.inviteCodes`，当前为 `geo0930`（不区分大小写），兑换后永久享有会员权益、不限张数（本地缓存）。
  2. **开通会员（有额度）**：

     | 方案 | 价格 | 额度 | 有效期 |
     | --- | --- | --- | --- |
     | 单张解锁 | ¥1.29 | 当前这张 | 本次使用期间 |
     | 月度会员 | ¥14.9 | 120 张 / 月 | 30 天 |
     | 年度会员 | ¥109.9 | 2000 张 / 年 | 365 天 |

     价格（单位：分）、额度、有效期均在 `membership.plans` / `membership.single` 中配置。
  3. **单张解锁**：只解锁当前这张照片，移除或重新选图后需再次解锁。
- **额度规则**：每保存一张无水印海报消耗 1 个额度；同一张照片在本次会话内再次保存不重复计费。每次购买是独立的一包额度（有效期从购买时起算），多次购买可叠加，优先消耗最早到期的一包。额度用完或到期后水印恢复。
- **超出额度**：保存时额度不足会提示“购买额外的月度或年度会员”，可选择仅下载额度内的部分，或打开付费面板购买；额度完全用完则直接打开付费面板并提醒。购买成功后自动继续刚才的下载。
- 批量下载时，只会下载已解锁 / 额度内的照片。缩略图上带“水印”标记的是未解锁照片；标题栏右上角显示当前状态（如“会员 · 剩余 117 张”），点击可打开付费面板查看各额度包的剩余与到期时间。

### 接入真实支付 / 服务端校验

当前 `payment.mode` 为 `'mock'`：点击购买只弹窗确认并视为成功，**不产生任何扣款**，仅用于开发联调。邀请码与会员状态目前都只在客户端校验/缓存，用户可通过清缓存重置、也可被绕过，**正式收费前必须迁移到服务端**：

1. 开通云开发，把 `payment.mode` 改为 `'cloud'`。
2. 云函数 `createOrder`：入参 `{ kind: 'plan' | 'single', planId }`，用微信支付统一下单，返回 `{ orderId, payment }`（`payment` 为 `wx.requestPayment` 的参数）。
3. 云函数 `verifyInvite`：入参 `{ code }`，返回 `{ valid }`。
4. 支付回调中在服务端记录权益（会员到期时间 / 已解锁的照片），并在导出前由服务端确认；客户端 `utils/membership.js` 应改为从服务端拉取权益。

## 导出

预览 Canvas 按屏幕 dpr 渲染；保存时使用页面外的隐藏 Canvas，物理尺寸 1200 × 1600（逻辑 400 × 533.33 的 3 倍），经 `wx.canvasToTempFilePath` 输出 JPG 并调用 `wx.saveImageToPhotosAlbum`。

## 说明与限制

- 必须选择原图（`sizeType: ['original']`），压缩图会丢失 EXIF；读取失败会提示并引导 `wx.chooseLocation` 手动选点（GCJ-02 会自动转换为 WGS-84）。
- 内置 EXIF 解析器取代 `exif-js`（后者依赖 DOM/XHR，无法在小程序中运行），支持 JPEG，并对 HEIC 做头部扫描兜底。
- 图片的 EXIF 方向（Orientation）目前依赖微信 Canvas 对图片的默认处理，未做额外旋转。
